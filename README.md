# Final Fight native browser playtest

Public runtime build only. Recovered Bred, Dug, Jake and Simons controllers use original health, defense, colors and weighted attack scripts, including leaping attacks. Guy, Cody and Haggar can move, jump, chain standing punches, use ordinary/downward air attacks, grab, knee, throw, take damage, fall and recover; Haggar can carry and piledrive. All three characters have backward combo throws and hit-dependent-cost escape specials. Stationary target mode is preserved. A three-enemy crowd encounter is the default, with original deferred contact ordering and special knockback on both sides. Single-enemy and stationary modes remain available. Fixed screen: stage entry/collision/progression, other enemy families/bosses, remaining moves, lives/respawn and additional audio are unfinished. Original Slum music and recovered punch, air-attack, escape and contact cues use native Web Audio playback. Select Enable audio.

No emulator or ROM archive is included. Graphics and audio are converted runtime assets from the supplied Final Fight set; game content belongs to Capcom.
