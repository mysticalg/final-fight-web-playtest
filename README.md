# Final Fight native JavaScript game

One continuous native JavaScript game: the opening gang/Jessica sequence and map, Slum street/room/rooftop with Damnd, then four Subway areas through Sodom. Choose Guy, Cody or Haggar. Weapons, containers, items, three lives, Continue and section music changes are connected. Newly added Andore, Roxy/Poison, knife-runner and Sodom decision timing is provisional. Later stages, further enemy moves, scenery effects and cutscenes remain unfinished.

No emulator, CPU interpreter, WebAssembly emulator or ROM archive is included. Original graphics/audio are converted runtime media; the game content belongs to Capcom.
