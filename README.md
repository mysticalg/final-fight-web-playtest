# Final Fight native JavaScript game

One scrolling game flow, connecting the Slum street, room and rooftop fight with Damnd. Choose Guy, Cody or Haggar, fight enemies, break containers and collect items. Three lives and Continue are connected. Timed encounter waves, later stages, weapons and full audio remain unfinished.

No emulator, CPU interpreter, WebAssembly emulator or ROM archive is included. Original graphics/audio are converted runtime media; the game content belongs to Capcom.
