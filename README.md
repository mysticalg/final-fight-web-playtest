# Final Fight native browser playtest

Public runtime build only. A recovered Bred controller approaches, repositions and uses jabs, kicks and uppercuts. Guy, Cody and Haggar can move, jump, chain standing punches, use ordinary/downward air attacks, take damage, fall and recover. Stationary target mode is preserved. One enemy on a fixed screen: stage entry/collision/progression, other enemies, remaining moves, lives/respawn and audio are unfinished.

No emulator or ROM archive is included. Graphics are converted runtime assets from the supplied Final Fight set; game content belongs to Capcom.
