# Final Fight native browser playtest

Public runtime build only. Recovered Bred, Dug, Jake and Simons controllers use original health, defense, colors and weighted attack scripts, including leaping attacks. Guy, Cody and Haggar can move, jump, chain standing punches, use ordinary/downward air attacks, grab, knee, throw, take damage, fall and recover; Haggar can carry and piledrive. All three characters have backward combo throws and hit-dependent-cost escape specials. Stationary target mode is preserved. One enemy on a fixed screen: stage entry/collision/progression, other enemy families/bosses, remaining moves, lives/respawn and audio are unfinished.

No emulator or ROM archive is included. Graphics are converted runtime assets from the supplied Final Fight set; game content belongs to Capcom.
